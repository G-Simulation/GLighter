# Sicherheit / Security

**Deutsch:** Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über GitHub: Reiter **Security → Report a vulnerability**, oder über das Kontaktformular auf https://www.gsimulations.de/gaslighter/. Wir melden uns so schnell wie möglich und veröffentlichen eine Korrektur, bevor Einzelheiten bekannt gemacht werden.

Unterstützt wird jeweils die neueste Version.

**English:** Please do **not** report security issues as public issues. Use GitHub **Security → Report a vulnerability** (private) or the contact form at https://www.gsimulations.de/gaslighter/. We will respond as soon as possible and release a fix before details are disclosed.

Only the latest version is supported.
