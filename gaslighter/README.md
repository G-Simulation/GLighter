# GasLighter – Lärmprotokoll / Noise log

Misst Lärm rund um die Uhr und protokolliert Störungen manipulationssicher – **ohne Tonaufnahme, ohne Cloud**. Notizen, Tagesverlauf, Ruhezeiten, Prüfkette und ein Lärmprotokoll zum Drucken oder als PDF.

*Measures noise 24/7 and logs disturbances tamper-evident – **no audio recording, no cloud**. Notes, daily chart, quiet hours, checksum chain and a printable noise report.*

- Kostenlos: Aufzeichnung, Protokolle, Lärmprotokoll, Export, Sicherung / Free: recording, reports, noise report, export, backup
- **GasLighter Pro** (Jahreslizenz, kein Abo / yearly licence, no subscription): Import einer Sicherung, erweiterte Einstellungen, externe Geräte, tägliche Sicherung auf NAS / backup import, advanced settings, external devices, daily NAS backup – [gsimulations.de/gaslighter](https://www.gsimulations.de/gaslighter/#buypro)

Sprache / language: Deutsch oder English (Einstellungen → Allgemein → Sprache / Settings → General → Language).

Nach der Installation **GasLighter** in der Seitenleiste öffnen; das Handbuch steht in der App unter **📖 Handbuch** und im Reiter „Dokumentation“.
After installing, open **GasLighter** in the sidebar; the manual is in the app under **📖 Manual** and in the "Documentation" tab.
